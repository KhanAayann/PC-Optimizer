⚡ Vortex Optimizer

Vortex Optimizer is a lightweight Windows PC tweaking tool built to improve system performance, reduce lag, and enhance gaming experience. It provides easy one-click optimizations for cleaning junk files, disabling unnecessary services, and applying performance-focused Windows settings.

🚀 Features
🧹 Clear temporary files and system junk
♻️ Empty Recycle Bin instantly
🎮 Enable Game Mode for better gaming performance
⚙️ Disable unnecessary Windows services
✨ Apply performance-based system tweaks
🎬 Optional background video toggle UI feature
🛠️ Built With
Python 🐍
Tkinter (GUI)
PowerShell commands
tkvideo (for video playback)
Pillow (image handling)

📦 Requirements:
Install required modules by Running Requirment.py file

▶️ How to Run
python Vortex.py in CMD or Terminal

Make sure you run it as Administrator for full functionality.

⚠️ Disclaimer:
This tool modifies system settings and services. Use responsibly and only if you understand the changes being made. Some tweaks may require a system restart.
